## Problem

In task detail, Depends on, Blocks, and the phase chip are plain text, and phase detail lists its tasks as plain text. To follow a link you must go back to the dashboard and find the row.

## Approach

- Task detail (`TaskDetailScreen` in `scripts/dashboard_app.py`): render Depends on, Blocks, and the phase as one focusable link list. `enter` on a task opens its task detail; `enter` on the phase opens the phase detail. `esc` pops one screen, so a chain of links walks back in order.
- Phase detail (`PhaseDetailScreen`): the Tasks panel becomes a focusable list; `enter` opens that task's detail.
- Remove the guards that stop a detail screen from opening another (`open_task` checks the current screen, `check_action` blocks `open_task`/`open_phase` on detail screens) only as far as these links need; dashboard keys stay blocked on detail screens.
- Keep the 60-column layout and the existing c/g/r keys on each screen.

## Exit criteria

- Pilot tests: from a task detail, enter on a dependency opens it, enter on the phase opens the phase detail, enter on a phase task opens it, and esc walks back screen by screen to the dashboard.
- A tmux popup test walks such a chain; README documents the links; the full suite passes.
