## Problem

Waiting task rows append every unfinished dependency slug as `waits on a, b, c, …`. The task column allows wrap, so long lists become multi-line rows, stretch the table, and push other tasks off screen ([issue #3](https://github.com/andrewy1n/se-workflow/issues/3)).

## Approach

Decision: drop-waits-on-from-row. Remove the `waits on …` note from `title_cell` so waiting rows show only title plus the size/estimate/executor suffix. Full dependency lists stay on task detail (Depends on). Model `waits_on` may remain; row rendering drops it. Update unit, app, and tmux tests that expected the note in the table.

Tasks (all `executor: subagent`):

1. `drop-row-waits-on` — stop appending the waits-on note in `dashboard/tasks.py` `title_cell`; rewrite unit and pilot assertions (and tmux needles) that required `waits on` in the row; keep a regression that task detail still lists Depends on. Cover R1–R3.
2. `verify-waits-on-compact` — depends on `drop-row-waits-on`. Integration pilot through the dashboard app: a waiting row with several unfinished deps has no `waits on` and stays one line; detail still shows Depends on; related suite slice passes.

Collision notes: only `dashboard/tasks.py` title rendering and waits-on row assertions in `tests/test_dashboard_tasks.py`, `tests/test_dashboard_app.py`, and `tests/test_tmux_integration.py`. No parallel shared files beyond that single wave of one task.

Size: one sitting. Human stops: plan review; then landing after verification.

## Exit criteria

- Waiting rows with many unfinished dependencies stay one line at typical widths with no `waits on` in the title cell (verified by dashboard app pilot through the real entry point).
- Task detail still lists Depends on links for those dependencies (verified by the same pilot / detail assertion).
- Suites that previously asserted row `waits on …` pass against the dropped form (`uv run --with textual --with pytest python -m pytest tests/test_dashboard_tasks.py tests/test_dashboard_app.py -q -k 'waits or title_cell or waiting_row'` and tmux needle update if marked).
