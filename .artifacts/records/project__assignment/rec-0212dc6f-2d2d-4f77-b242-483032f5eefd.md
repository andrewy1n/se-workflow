### Requirements (R5, R10, R11)

R5: When the selected phase's body has a `## Landing` section, the selector area shows its branch, the number of commits it has that `main` lacks, and `merged` or `not merged`; a branch that does not exist yet shows `no branch yet`. A phase without Landing shows nothing.

### Design Invariants

`load_snapshot` stays free of git calls; landing is merged in by the app and the status scripts. Every git command is read-only. Item ids for alerts are record ids, or `merge:<phase>` for branch items, so a refresh does not re-alert.

### Design Assumptions
