## Description

Teach skills to clear human-dismissible Needs-you sources when the user settles them, and have engage remind without blocking routing.

## Approach

1. In skills/kinds-and-focus.md, define human-dismissible kinds (blocking-question, open-question, needs-human, unsigned-check) and the clear commands: continuity-question update --transition answered; finding supersede with needs none; manual check-run correct with signed_by.
2. In skills/engage/SKILL.md, after focus is named, list open human-dismissible items for that effort and remind the agent to clear them when settled; do not refuse to route because they are open.
3. In discuss, plan-phase, verify-work, and execute-phase (where each opens a gate), document the matching clear next to the create path so closing is not ad-hoc.
4. Add or extend tests (test_discuss_skill.py and/or a focused skill doc test) so engage reminds and clear commands are asserted; keep test_skill_contract_consistency.py green for every new CLI invocation.
