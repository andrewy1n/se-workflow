## Description

Repeat size, minutes, and executor as chips on the task detail screen.

## Approach

Read design `estimate-view`, Interfaces. `TaskDetail.size`, `estimate_minutes`, and `executor` are already set by `estimate-model`. Do not edit `dashboard/model.py` or `dashboard/tasks.py`.

Edit `dashboard/task_detail.py`, add `tests/test_dashboard_estimate.py`, and update the existing chip assertions in `tests/test_dashboard_app.py`. Wave 2 has finished with that test file.

Write `test_estimate_view_chips` first. It is a Textual pilot at 60 columns that opens `TaskDetailScreen` for three seeded tasks: size `M`, `estimate_minutes` 25, executor `subagent`; no size, `estimate_minutes` 0, executor `inline`; and neither field set. Assert the chips contain `M`, `25m`, and `executor subagent` for the first, `0m` and `executor inline` for the second, and `executor subagent` for the third. The third chip line has no size token and no `0m`.

In `detail_chips`, after the assignee chip when assignee is set, otherwise after the wave chip, append muted chips: the size when it is non-empty, `{n}m` when `estimate_minutes` is not `None`, and `executor {executor}` always. Keep the existing wrap: a chip that does not fit starts a new line, and a chip is never split.

Update the exact chip strings in `tests/test_dashboard_app.py` so they include ` · executor subagent` for details built without an executor. That includes `test_detail_chips_show_running_time_from_the_running_since_stamp` and `test_chips_never_split_a_label_from_its_value_when_narrow`. On the narrow line, `executor subagent` stays one chip.
