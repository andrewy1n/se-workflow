## Description

Create an executable `se-workflow.tmux` at the repo root. It finds its own directory, reads `@dashboard-popup-key` and `@dashboard-pane-key` (defaults `A` and `S`), and binds the popup and side-pane keys to `dashboard/bin/dashboard` in the pane directory. TPM and `run-shell` both run it. Add `tests/test_tmux_entry.py` (tmux marker) that loads the script into an isolated tmux server.
