## Description

Add `project:backlog-item` and a handoff role for open items so deferred work can live in the store.

## Approach

Edit `contract/project-design.json` only (copy to `.artifacts/project-design.json` and `adaptive-artifacts resolve`). Do not patch the adaptive-artifacts runtime.

Add record `backlog-item` on pattern `current-status`:
- purpose: deferred work parked on an effort until promoted or dismissed
- payload: `effort`, `status`; optional `source`, `phase`
- `payload_enum.status`: `open`, `promoted`, `dismissed`
- `payload_references.phase`: `project:phase`
- no required_sections (body holds the parked description)

Add a handoff view role (e.g. `backlog`) occupying `backlog-item`, selecting lifecycle `active` and `payload.status` equals `open`, with `requires_payload` including `effort` and `status`. Prefer `equals open` over `not_equals` so missing status never looks open.

Keep `feedback` unchanged. Extend ensure-store currency text only in a later skills task — this task owns the contract file alone.

Prove with `uv run --with textual --with pytest python -m pytest tests/test_contract_self_consistency.py -q`.
