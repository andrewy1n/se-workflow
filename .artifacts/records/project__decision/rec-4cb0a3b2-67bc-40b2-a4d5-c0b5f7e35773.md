## Rationale

The store is one writer. The parent writes `.artifacts` on the primary checkout, and the phase branch commits code only. A second checkout of `.artifacts` goes stale and conflicts when the branch merges.

## Counter-argument

Committing the store from the worktree would put records and code in one commit. Two checkouts of the same store still diverge as soon as the parent writes a record on the primary checkout.
