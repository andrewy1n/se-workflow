## Rationale

dashboard_app.py has 1726 lines. The move rewrites every import in it anyway. The task code is the largest cohesive part, so a split into modules at this point costs little extra. The user chose to split while moving.

## Counter-argument

A pure move gives a small diff that a reviewer can check by eye. Mixing a split into it hides moves inside edits, and one failing test then cannot tell a path error from a split error. Do the move first and the split in a later phase to keep each step verifiable.
