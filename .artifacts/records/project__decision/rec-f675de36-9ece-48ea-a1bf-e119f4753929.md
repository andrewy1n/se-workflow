## Rationale

Records stay the only authority and the dashboard is one more derived view. The skills already write every fact the dashboard needs, so no skill changes. Any contract, not only se-workflow, gets a live view from the same renderer.

## Counter-argument

A standalone script is faster to build and style freely. Contract view roles cannot express everything a rich TUI wants (layout, colour, counts), so the runtime may grow view parameters that only the dashboard uses.
