## Rationale

The phase gate is the moment the work is done, so the git close belongs there: commit code on the phase branch, merge that branch into `main`, then commit the store on the primary checkout. Push publishes the repo, so it stays a human stop named in the phase body. The default close is local.

## Counter-argument

Leaving commit and merge until the user asks keeps a person in the loop for every landing. That is how phases finish today, and the files are already on `main` by the time the question is asked.
