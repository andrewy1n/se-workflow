## Problem
Claude Code transcripts are raw JSONL. No tool turns them into per-session numbers.

## Approach
A script in scripts/ reads ~/.claude/projects/*/*.jsonl and emits one JSON summary per session: tool calls by type, failures, retries, permission prompts, turns, token cost, skill invocations. The parser tolerates unknown fields.

## Exit criteria
Running the script on this machine's transcripts emits valid JSON for every session. A test covers a fixture transcript with known counts.
