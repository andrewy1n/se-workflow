## Problem

Needs-you items stay visible after the human has already answered in chat, because skills open continuity-questions, needs:human findings, and unsigned manual checks but almost never clear them; only plan-review is answered on approval. The dashboard correctly mirrors open records, so the user has to tell an agent to close them by hand.

## Approach

decide at plan-phase — mixture of skill close rules and dashboard dismiss actions

## Exit criteria

Skills close or clear Needs-you sources when the user answers them in an agent session, and the dashboard can dismiss the same item kinds without an agent; both paths leave the store consistent and Needs you empty once settled (verified by skill-contract tests and dashboard pilot tests).
