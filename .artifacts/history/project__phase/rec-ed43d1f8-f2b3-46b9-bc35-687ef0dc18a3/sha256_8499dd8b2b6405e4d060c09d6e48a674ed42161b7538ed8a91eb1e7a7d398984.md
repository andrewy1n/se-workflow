## Problem

Repair and evaluate work live in failed attempts, observations, findings, continuity questions, and assignment amendments, but the dashboard only surfaces some of those as Needs you items. Everything else is invisible unless you open records by hand. Delivery efforts and repair efforts share the same task table as delivery work. The task detail shows that a task was assigned and reported, but not what the executor was told or what it returned.

## Approach

Decisions: journal-screen, journal-order, journal-types, kind-journal-panel, task-agent-work. Run as structured work: specification `journal-view`, design `journal-view`.

`J` opens a Journal screen (phase or effort via `a`). Repair/evaluate efforts get an open-items panel above the task table. Task detail gains Agent work blocks (assignment, amendments, report) with collapse and `o`. Starts after `spec-view` (reuses pager). Can run beside `evidence-matrix`; shared collision is `dashboard/model.py` loaders.

Tasks (all `executor: subagent`):

1. `journal-model` — `load_journal`, scope, open-first order, kind/`journal_open` on snapshot. Cover with `-k journal` model tests.
2. `journal-agent` — Agent work on task detail (bodies, amendments, collapsible blocks). Independent of screen. Cover with journal/app tests for R8.
3. `journal-screen` — `JournalScreen`, `RecordDetailScreen`, filter, `J`/`a`/`o`. Depends on model. Cover with `tests/test_dashboard_journal.py`.
4. `journal-panel` — kind Journal panel on main EffortPane. Depends on model. Cover with app pilots for R7.
5. `verify-journal-view` — integration and full suite.

Collision notes: `dashboard/journal.py` and journal screen belong to `journal-screen`. Snapshot `kind`/`journal_open` belong to `journal-model`. `task_detail.py` / Agent work belong to `journal-agent`. `EffortPane` panel belongs to `journal-panel`. Do not edit phase_screen Evidence matrix code.

Size: more than one sitting. Human stops: plan review; then landing after verification.

## Exit criteria

- Item selection per type, phase scoping, open-first ordering, the kind panel rule, and the assignment and report bodies hold against seeded stores (`tests/test_dashboard_model.py`, `tests/test_dashboard_journal.py`).
- `J`, `a`, Enter, Esc, collapsed and expanded agent sections, and `o` with the pager stubbed behave as specified in a Textual pilot (`tests/test_dashboard_journal.py`, `tests/test_dashboard_app.py`).
- The full suite passes.
