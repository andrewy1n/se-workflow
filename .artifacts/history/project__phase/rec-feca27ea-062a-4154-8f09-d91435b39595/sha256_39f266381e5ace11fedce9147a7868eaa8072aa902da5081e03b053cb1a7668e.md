## Problem

The Needs you panel is the main reason to open the dashboard, but it is a static block: you cannot select an item, long text stays clipped, and there is no route to the related task or record body. A finished effort lands on an empty "No tasks match" box under Active, and finished efforts sit among live ones in the tab bar.

## Approach

- Model (`scripts/dashboard_model.py`): give each needs-you item its record type, full text, body, and the work-item it belongs to (same slug or slug prefix, same effort). Add a derived finished flag on EffortView (every phase and counted task done).
- App (`scripts/dashboard_app.py`): replace the Needs you Static with a focusable list. `n` focuses it, `esc` returns to the task table. `enter` opens the task detail when the item has a task, else a Needs-you detail screen with the full text and body. `c` copies the subject.
- App: on a finished effort, the empty Active tab says "All N tasks done" instead of "No tasks match". Finished efforts sort after live ones and their tab label is dimmed.
- No goal-complete needs-you item: goals cannot close in the runtime, so the dashboard only derives and shows finished efforts (decision finished-effort-derived).
- Start execution after dashboard-bugfix finishes. bugfix-needs-you-data changes the same needs-you code (tab count and unsigned-check label).

## Exit criteria

- Model tests cover the new item fields, task linking, and the finished flag.
- Pilot tests: `n` focuses the list, arrows move, `enter` opens the task detail or the Needs-you detail, `esc` returns; a finished effort shows "All N tasks done" and sorts last.
- A tmux popup test walks these keys, the full suite passes, and README documents `n` and the new screen.
