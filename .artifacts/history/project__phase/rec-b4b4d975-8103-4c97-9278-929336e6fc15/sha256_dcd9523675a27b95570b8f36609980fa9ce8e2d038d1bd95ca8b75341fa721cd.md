## Problem

The dashboard app, model and status line live in scripts/ next to unrelated tooling. dashboard_app.py has 1726 lines, with the task table, filter, sections and task detail mixed with the other screens.

## Approach

Decisions: dashboard-package-layout, dashboard-task-split.

Create a top-level `dashboard/` package next to `scripts/`. It holds the model, the status line, the launcher and the app. Split the app so the task table, filter, section rows, status cells and task detail screen are in their own module. Update the tmux conf, README, sync-plugin.sh and the tests' imports and paths. Leave no wrappers in scripts/.

## Exit criteria

The dashboard code lives in its own package outside scripts/. The task code is in its own module. The plugin and tmux entry points still start the dashboard. The full suite passes.
