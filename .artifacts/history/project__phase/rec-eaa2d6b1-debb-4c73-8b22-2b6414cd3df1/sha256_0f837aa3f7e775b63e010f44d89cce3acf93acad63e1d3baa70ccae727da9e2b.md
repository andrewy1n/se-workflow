## Problem

The Needs you status tab filters tasks by needs-you subject, so effort-level questions and items whose subject is no task slug never count: the tab said 0 while the panel listed 3. Unsigned manual checks show the raw criterion record id (`rec-… pass`) instead of what was checked.

## Approach

- Remove the Needs you status tab (user decision). Six tabs remain: Active, Running, Ready, Waiting, Done, All on keys 1-6. The Needs you panel is the one source, and its border title shows the count ("Needs you 3"). Update `STATUS_TABS`, bindings, `--once` output, README, and the tests that walk tabs.
- In `dashboard_model.py`, label an unsigned check with its acceptance criterion and the task slug, falling back to the record subject when the acceptance is gone. The snapshot already lists acceptances.

## Exit criteria

- Pilot tests: six status tabs on keys 1-6, no Needs you tab, panel title shows the item count.
- Model test: an unsigned check reads as its criterion text, never a `rec-` id.
- A tmux popup test walks the six tabs and sees the counted panel title; the full suite passes.
