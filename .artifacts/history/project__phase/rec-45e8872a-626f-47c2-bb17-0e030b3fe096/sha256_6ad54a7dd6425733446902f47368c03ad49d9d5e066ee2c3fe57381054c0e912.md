## Problem

Waiting task rows append every unfinished dependency slug as `waits on a, b, c, …`. The task column allows wrap, so long lists become multi-line rows, stretch the table, and push other tasks off screen ([issue #3](https://github.com/andrewy1n/se-workflow/issues/3)).

## Approach

decide at discuss — compact waits-on so one task stays one row (count, truncated list, or detail on demand)

## Exit criteria

A waiting row with many unfinished dependencies stays one line in the task table at typical widths (unit and pilot tests); the unfinished dependency list remains available from task detail; existing waits-on assertions are updated to match the chosen compact form.
