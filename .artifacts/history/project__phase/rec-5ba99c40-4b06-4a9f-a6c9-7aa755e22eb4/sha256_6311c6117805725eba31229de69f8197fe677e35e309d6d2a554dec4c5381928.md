## Problem

`run-facts` stores `size` and `estimate_minutes` on each work-item and defines how those minutes add up, and it does not change the dashboard. The sitting line and the executor are already stored. None of them appear on the task table, so a scan still does not show how big a task is, how long its agent should take, or how long the phase should take.

## Approach

Decision: estimate-titles. Also follows glance-run-facts and task-agent-estimate.

This phase starts after `run-facts` is on main, because it reads `size` and `estimate_minutes`. It edits the dashboard. `evidence-view` also edits those files, so this phase starts after that branch is on main too.

The phase header, after the done/total count, shows the sitting phrase when the body has one, then the derived elapsed minutes. Each task title shows its size, its own minutes, and its executor. Missing size or missing minutes are left out. A missing executor is shown as `subagent`. When some counted tasks have no `estimate_minutes`, the header keeps the partial total and shows how many are unset. Clipping shortens the title and keeps the suffixes. Task detail repeats size, minutes, and executor as chips.

The header minute figure is the wave rule from task-agent-estimate. It is not the sum of every task.

## Exit criteria

A seeded phase with a `Size: more than one sitting` line and task estimates shows `more than one` and the derived elapsed minutes on the phase header, and each task title shows its size, minutes, and executor. Verified by `tests/test_dashboard_model.py` and `tests/test_dashboard_app.py` at 60 columns.

A phase where two counted tasks have no `estimate_minutes` shows the partial total and `2 unset`. A phase where none have an estimate shows no minute suffix. A task with no size omits the size token. The same tests.

The header minute figure matches the wave rule: inline minutes in a wave add, a subagent wave contributes its longest task, and those wave figures add in order. A model test with the parallel-wave case.

Task detail shows chips for size, minutes, and executor. An app test at 60 columns opens the task. A long title keeps the suffix. The phase diff does not change `contract/project-design.json`.
