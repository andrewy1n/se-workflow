## Architecture

`contract/project-design.json` adds optional `size` and `minutes` to `project:work-item`. `skills/plan-phase/SKILL.md` requires both on every new work-item and states how a reader totals them. Nothing in `dashboard/` changes. The sitting line stays prose in the phase body.

A later phase can render these fields. This phase's job ends when the contract accepts them and `plan-phase` is required to write them.

## Interfaces

- Work-item payload `size`, optional, enum `S`, `M`, `L`.
- Work-item payload `minutes`, optional, a non-negative integer.
- `plan-phase` sets both in the same payload as `executor`.
- Derived, not stored:
  - An inline wave's elapsed minutes are the sum of its tasks' `minutes`, skipping blanks.
  - A subagent wave's elapsed minutes are the maximum of its tasks' `minutes`, skipping blanks.
  - Phase elapsed minutes are those wave figures added in wave order, skipping a wave that has no minutes.
  - A size tally is the count of `S`, `M`, and `L` on the phase's tasks.
- The phase payload stays `title`, `ordinal`, and `effort`.

## Decisions

glance-run-facts, task-agent-estimate.

## Invariants

Absent `minutes` are not zero. `size` and `minutes` are not derived from each other. The sitting line remains `one sitting` or `more than one`. Minutes refer to `payload.executor`, and a missing executor means subagent. Assignee is not the rollup key. There is no hours field.

## Assumptions

`minutes` is a whole number. A wave's tasks share one executor. The derived `wave` is the grouping. Old work-items have neither field until a later edit, and totals skip them.

## Tradeoffs

There is no single stored phase total, and phase elapsed time is not the sum of every task. Parallel subagent work counts once, as the longest task. S, M, and L can disagree with the minutes, and both stay so the disagreement is visible. Minutes are a finer guess than hours, and a long phase becomes a large minute count. Loading nothing new into the dashboard keeps this phase off the files `evidence-view` is editing.

## Risks

Minutes will still be guessed. A partial total, when some tasks omit minutes, can be read as the whole phase. The later display phase has to use the wave rule; summing every task's minutes would contradict this decision. `evidence-view` is still in progress, so this phase stays away from `dashboard/` until that branch is on main.
