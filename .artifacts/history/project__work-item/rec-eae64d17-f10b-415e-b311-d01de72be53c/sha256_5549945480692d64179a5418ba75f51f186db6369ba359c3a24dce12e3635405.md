## Description

Render the evidence model on existing surfaces: the phase header tally, phase detail evidence sections, the stepper stage word, the Release ready badge, Needs-you lines, and activity lines. Opening the requirement screen is wave 3.

## Approach

- `dashboard/tasks.py`: a phase section row whose `PhaseRow.evidence` is set appends `R n/m verified` and, when release ready, `Release ready`.
- `dashboard/app.py` stepper: the current phase segment appends ` · <stage>` when it has evidence; keep the 60 column wrap rules.
- Effort tab label: append a Release ready marker when `EffortView.release_ready`.
- `PhaseDetailScreen`: for a structured phase add the stage strip (eight stage names, current one highlighted, wraps at 60), specification weight and non-goals, design decisions, the latest integration-report result with its Conflicts section, and a requirement list (id, status, next, task count; unassessed rows show the check result dimmed). The list is an `OptionList` whose enter does nothing yet.
- Needs you: readable lines for `loop-route` (requirement, status, next) and `integration` (phase, result) items.
- Activity: render the new kinds; failed ones in the error colour with the existing failed glyph.
- Every addition branches on `evidence is None`; a simple phase renders exactly as before.

Do not edit `dashboard/model.py`, `dashboard/task_detail.py`, or `dashboard/requirement_detail.py`, and do not import `RequirementDetailScreen`. Pilot tests go in `tests/test_dashboard_app.py`, names containing `evidence`, at 60 and 120 columns.
