## Description

Replace the stepper with a selectable phase strip, add keyboard/mouse navigation, render the wave strip, and wire the finished-effort toggle and key help.

## Approach

1. Replace `PhaseStepper`/`stepper_text` with a `PhaseSelector` widget that renders: done count, selected phase, in-progress phases with ●, next planned phase, and `All phases`. Highlight the selected segment.
2. Add app state `selections: dict[str, Selection]` and update `EffortPane.show` to pass the resolved selection into model helpers and table helpers.
3. Bind `[`/`]` to step selection by ordinal (with wrap to All phases), `P` to open a filterable `OptionList` picker, and click on selector segments to select.
4. Add `WaveStrip` widget or inline rendering that shows `w<n>` plus one glyph per task per wave, falling back to one glyph per wave when space is tight.
5. Keep `Needs you` and `Activity` effort-wide regardless of selection.
6. Bind `p` to open the selected phase detail (in All phases it still opens the cursor row's phase).
7. Bind `f` to toggle finished efforts and show `+N finished` in the effort tab bar; a finished effort with Needs you items stays visible.
8. Bind `?` to toggle the key help panel.
9. Add Textual pilot tests in `tests/test_dashboard_app.py` for selector, picker, navigation, wave strip, finished toggle, and key help.
