## Description

Teach plan-phase to record the recipe, the wave executor, and the phase run facts before it opens plan review.

## Approach

Edit `skills/plan-phase/SKILL.md` so each new work-item body includes `## Approach`, the implementation recipe, and payload `executor` is `inline` or `subagent`. State that every task in a wave uses the same executor. The phase body records size as `one sitting` or `more than one`, the human stops, and the areas parallel tasks share. Do not open the plan-review question until those are present.

Add `executor` to the work-item payload in `contract/project-design.json`. Do not add `## Approach` to `required_sections`, so existing work-items stay valid. Missing `executor` means `subagent`.

Document that rule in one short paragraph in `skills/kinds-and-focus.md` and in the README use section.

Add `tests/test_plan_wave_rules.py`, in the style of `tests/test_discuss_skill.py`, asserting the executor values, the shared-wave rule, the phase run facts, and the plan-review gate.

Do not edit `skills/execute-phase/SKILL.md` or `tests/test_execute_wave_dispatch.py`.
