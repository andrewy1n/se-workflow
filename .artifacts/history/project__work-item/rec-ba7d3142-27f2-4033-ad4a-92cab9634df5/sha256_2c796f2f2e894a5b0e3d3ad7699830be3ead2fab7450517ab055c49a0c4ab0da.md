## Description

Show open backlog items for the selected effort in a separate Backlog panel, with promote and dismiss through the CLI.

## Approach

Do not edit `contract/project-design.json` or skills in this task.

1. **Model** (`dashboard/model.py`): load active `project:backlog-item` records with `payload.status=open` into each `EffortView` (new field, e.g. `backlog`). Group by `payload.effort`. Never add them to `_needs_you` / Needs you.
2. **Actions** (extend or sibling of `dashboard/dismiss.py`): promote = supersede status `promoted` (+ optional phase); dismiss = supersede status `dismissed`. Same Target/binary as Needs you dismiss. Refuse non-backlog records.
3. **Prompt**: on promote, copy an agent prompt naming the effort and item so the user can continue with discuss (or incidental) in chat — mirror Needs you prompt-copy; do not start discuss inside Textual.
4. **UI** (`dashboard/app.py` and related): Backlog panel on the effort pane (separate from Needs you, Tasks, Journal); detail for an item with promote/dismiss. Navigation/keying consistent with existing panels.
5. **Tests**: model tests for open-only per effort; pilots through the app entry point for panel visibility and promote/dismiss CLI path (`tests/test_dashboard_model.py`, `tests/test_dashboard_app.py` with `-k backlog` or dedicated module).

Prove with:
`uv run --with textual --with pytest python -m pytest tests/test_dashboard_model.py tests/test_dashboard_app.py -q -k backlog`
