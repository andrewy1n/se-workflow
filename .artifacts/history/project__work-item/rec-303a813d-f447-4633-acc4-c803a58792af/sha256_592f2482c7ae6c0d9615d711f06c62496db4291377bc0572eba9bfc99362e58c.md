## Description

Prove the plan and execute skills agree on inline and subagent, and that a missing executor means subagent.

## Approach

Add `tests/test_wave_executor_phase.py`. It reads `skills/plan-phase/SKILL.md` and `skills/execute-phase/SKILL.md` and asserts both name `inline` and `subagent`, both treat a missing executor as `subagent`, and execute-phase stops when a wave's executors disagree.

Run:

`python3 -m pytest tests/test_plan_wave_rules.py tests/test_execute_wave_dispatch.py tests/test_wave_executor_phase.py tests/test_discuss_skill.py -q`

Do not change skill behavior except to fix a failure that is a real inconsistency between the two skills. Do not edit the two implementation test files except to import a shared helper if the agreement test needs one, and then keep the helper in `tests/test_wave_executor_phase.py`.
