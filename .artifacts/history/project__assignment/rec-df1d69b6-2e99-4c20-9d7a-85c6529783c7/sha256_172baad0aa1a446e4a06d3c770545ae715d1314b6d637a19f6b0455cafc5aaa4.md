### Requirements (R6, R7)

R6: A done phase with a Landing section whose branch exists and is not merged into `main` adds a `Merge branch` Needs you item. Enter on it opens the Needs you detail with the branch and ahead count.
R7: A running task is quiet when its latest record is older than twice its `estimate_minutes`, or 60 minutes when it has none. Its status reads `running <time> · quiet` in the warning colour, and its wave strip glyph uses the warning colour. Quiet tasks add no Needs you item.

### Design Invariants

`load_snapshot` stays free of git calls; landing is merged in by the app and the status scripts. Every git command is read-only. Item ids for alerts are record ids, or `merge:<phase>` for branch items.

### Design Assumptions

Phase bodies name the branch as `phase/<phase-slug>`; backtick after `branch` overrides. Default base `main`.

### Decisions

- landing-display: selected phase line shows Landing branch/ahead/merged; done+unmerged is Merge branch Needs you item
- quiet-threshold: quiet flagged on row and wave strip only, not in Needs you
