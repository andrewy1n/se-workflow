## Orientation

Inline task in phase-selector wave 1. Implement in the worktree at /home/andre/se-workflow--phase-selector. Code files: dashboard/app.py, tests/test_dashboard_app.py. Depends on model helpers from phase-model-selection and table helpers from phase-table-scope.

## Quoted requirements

R2: The selector line replaces the stepper. It shows earlier done phases as a muted count, the selected phase, every in-progress phase marked `●`, the next planned phase, and `All phases`. The selected segment is highlighted. A structured in-progress phase keeps its stage word. Segments wrap and clip by pane width as the stepper does today.
R3: `[` and `]` select the previous and next phase in ordinal order, with All phases after the last phase; they stop at the ends. `P` opens a picker listing All phases and every phase with its ordinal, state glyph, title, and done/total; typing filters it, Enter selects, Esc closes. Clicking a phase segment or `All phases` selects it; clicking the done count opens the picker.
R6: Needs you and Activity cover the whole effort whatever is selected.
R8: `p` opens the selected phase's detail. In All phases it opens the cursor row's phase as before.
R9: The selected phase shows a wave strip: `w<n>` then one status glyph per task in that wave, for example `w1 ✓✓  w2 ▶  w3 ◌`. When it does not fit the pane, each wave shows one glyph for its least-finished task. The task table has no wave column.
R11: Finished efforts are hidden by default. The tab bar shows `+N finished`, and `f` toggles showing them. A finished effort with Needs you items stays visible.
R12: `?` shows the keys available on the current screen and focused widget, including `[`, `]`, `P`, and `f`.

## Quoted design invariants and assumptions

The snapshot model stays independent of the selection: selection is UI state and filters a loaded EffortView.
Needs you and Activity content do not depend on the selection.
Status values and task order are unchanged.
Textual's key panel is available in the version `uv` resolves; if not, `?` pushes a small screen listing the active bindings instead.

## Quoted named decisions

quiet-header: Status tabs show a word and a dim parenthetical tally with no leading digit. The stepper becomes the phase selector: a done count, the selected phase, in-progress phases, the next phase, and All phases.
phase-selector-keys: [ and ] step through phases with All phases after the last; P opens a filterable phase picker; selector segments are clickable.
wave-strip: The selected phase shows a wave strip with one glyph per task per wave, and the task table drops the wave column.
finished-effort-toggle: Finished efforts are hidden behind f with a +N finished marker; a finished effort with Needs you items stays visible.
